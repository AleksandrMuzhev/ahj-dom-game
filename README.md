# Goblin Game

Игра, в которой нужно ловить гнома, появляющегося в случайных клетках игрового поля.

## Игровой процесс

- Гном перемещается по полю 4x4 каждую секунду
- Нужно кликать по клетке с гномом
- При промахе счётчик промахов увеличивается
- После 5 промахов игра заканчивается
